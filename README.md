## 🛠️ 食用方法 (How to Install & Use)

为了能够顺利运行这些脚本，你需要先在浏览器中安装“用户脚本管理器”扩展。

### 1. 安装脚本管理器 (Install Script Manager)
强烈推荐使用以下两款主流的脚本管理器（任选其一即可）：
- **[Tampermonkey (油猴)](https://www.tampermonkey.net/)**：功能强大，兼容性极佳，支持 Chrome, Edge, Firefox 等主流浏览器。
- **[Violentmonkey (暴力猴)](https://violentmonkey.github.io/)**：开源免费，界面简洁，性能优异。

### 2. 一键安装脚本 (Install the Script)
安装好扩展后，点击上方表格中的 **“点击安装”** 链接，进入 GreasyFork 脚本主页，点击绿色的 **“安装此脚本”** 按钮即可完成一键安装。

### 3. 享受体验 (Enjoy!)
安装完成后，只需重新刷新对应的目标网页，即可体验脚本带来的全新便利与增强功能！
